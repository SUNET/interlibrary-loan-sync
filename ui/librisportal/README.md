UI is the main ILL Bridge interface, intended for librarians and library staff. It focuses on managing interlibrary-loan workflows, including incoming and outgoing requests, request statuses, items, holds, lending/borrowing actions, and provider information. The interface should be simple and task-oriented, helping librarians quickly find requests, understand what action is required, and manage the daily ILL workflow without exposing unnecessary technical details. it should mainly talk directly to libris api (and some extra backend integration)
