UI is an internal administration and operations dashboard, intended for system administrators and technical staff. It focuses on monitoring Procrastinate jobs, workers, queues, scheduled tasks, and the Libris integration. Administrators should be able to see running and failed jobs, retry or rerun tasks, monitor Libris polling and synchronization, inspect errors, and verify the health of supporting services. Unlike the librarian UI, this interface is an operational control panel designed for troubleshooting and system monitoring.
